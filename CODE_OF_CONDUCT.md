# Code of conduct

difftop follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, be patient, and assume good intent. Harassment and
personal attacks aren't tolerated anywhere in the project.

To report a problem, contact the maintainers privately through
[GitHub](https://github.com/Seenko). Reports are handled confidentially.
