# Security policy

difftop only reads files; it never writes, runs, or sends anything. The
parts most likely to go wrong are reading untrusted files (theme files, and
files in watched folders) and printing their contents to the terminal.

To report a vulnerability, use GitHub's
[private vulnerability reporting](https://github.com/Seenko/difftop/security/advisories/new)
instead of opening a public issue. You'll get an answer within a week.

Only the latest release is supported.
